# c-practice
A collection of small projects I made while learning C#. Some are based on tutorials and help me practise programming fundamentals.

## Projects

- [Console Adventure Game](./console-adventure-game/) — A console game where the player moves around, fights a boss, and rescues a princess.
- [Console Adventure Game](./sword-of-the-hero/) — A console RPG where the player explores a forest, fights monsters, upgrades their weapon, and defeats a boss to obtain the Hero's Sword.

## Run the Game

Install the .NET 8 SDK, then run this command from the repository folder:

```bash
dotnet run --project ./console-adventure-game/入门实践.csproj
```

## Controls

- `W`, `A`, `S`, `D` — Move
- `J` — Confirm, fight, or interact
